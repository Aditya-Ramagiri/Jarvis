# ---------------------------------------------------------------------------
# Adrien optional dependencies.
#
# `start.sh` installs these ONE AT A TIME and tolerates failures, because each
# one costs exactly one feature when it is missing and Adrien is built to
# degrade rather than refuse to start:
#
#   openwakeword       -> no wake word; clients and `adrien chat` still work
#   webrtcvad-wheels   -> endpointing falls back to energy-only detection
#   chromadb           -> memory falls back to keyword matching
#   zeroconf           -> clients need a manual address instead of discovery
#   PyGithub           -> the GitHub tools report themselves unconfigured
#   mcstatus           -> no Minecraft server status
#   google-*           -> no Calendar or Gmail
#   pyautogui / pyobjc -> reduced macOS automation
#   rumps              -> no menu bar item (the service still runs)
#
# openwakeword is listed with --no-deps in start.sh: it declares a
# tflite-runtime dependency that has no wheel for Python 3.11+, and Adrien
# only ever uses its ONNX path. Its real runtime needs (numpy, onnxruntime,
# scipy) are covered here and in requirements.txt.
# ---------------------------------------------------------------------------
