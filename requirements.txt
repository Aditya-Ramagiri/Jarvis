# Adrien core dependencies (Python 3.11+)
#
#   ./start.sh          installs these, then the optional set
#   pip install -r requirements.txt -r requirements-optional.txt
#
# THIS FILE IS THE MUST-HAVE SET. Everything here is needed for the basic
# voice loop, and a failure installing any of it is fatal.
#
# Everything that can fail without taking Adrien down lives in
# requirements-optional.txt and is installed package-by-package, so one
# unresolvable wheel costs that one feature rather than the whole install.
# That split is not theoretical: openwakeword depends on tflite-runtime, which
# has no wheel for Python 3.11+ on Linux, and having it in this file meant a
# single `pip install -r requirements.txt` installed *nothing at all*.
# ---------------------------------------------------------------------------
